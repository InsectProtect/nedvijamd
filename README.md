# Доля

Мобильное веб-приложение для совместных вложений в квартиры. В нём видно, кто сколько вложил, на что потрачены деньги, как соотносятся план и факт, какая ожидается прибыль и как она делится.

## Возможности

- Аккаунты по email и паролю. Объектов сколько угодно, у каждого свой состав участников.
- Роли на объекте:
  - **Инвестор** — вносит взносы и расходы и получает долю прибыли.
  - **Прораб** — вносит только расходы на ремонт. Может получать долю с прибыли: процент или фиксированную сумму.
  - **Просмотр** — только смотрит.
- Каждый добавляет только свои операции. Внести операцию за другого участника нельзя. Изменить или удалить можно только свою операцию.
- Доли инвесторов и прораба ставит только создатель объекта.
- Операции бывают трёх видов: взнос, фактический расход (из своих денег или из общего котла) и плановый (ориентировочный) расход. План и факт сравниваются по категориям, перерасход подсвечивается.
- Прогноз продажи: ориентировочная цена, затраты и прибыль. Сначала выплачивается доля прораба, остаток делится между инвесторами.
- Взаиморасчёт показывает, кто кому должен доплатить, чтобы вложения совпали с долями.
- Фото чеков: камера или галерея. Перед загрузкой фото сжимаются на телефоне. Просматривать чеки можно прямо в приложении.
- Удаление объекта только с согласия всех участников сделки (инвесторов и прорабов). Перед удалением можно скачать выгрузку в CSV.
- Участников приглашают по ссылке, она действует 7 дней.

## Запуск

```
npm install
DATABASE_URL=postgres://... npm start
```

Таблицы создаются автоматически при старте (`schema.sql`).

## Деплой на Render

Тип сервиса — Web Service, Node.

- Build: `npm install`
- Start: `npm start`
- Переменная окружения: `DATABASE_URL` — строка подключения к Postgres (Neon).
